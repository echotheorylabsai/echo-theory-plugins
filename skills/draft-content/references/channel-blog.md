# Channel: Blog Post

## Structure

1. **Headline** — clear, benefit-driven, includes primary keyword. Aim for ≤60 characters for SEO.
2. **Introduction** (100–150 words) — hook with a question, statistic, bold claim, or relatable scenario. State what the post will cover. Include the primary keyword.
3. **Body sections** (3–5) — each with a descriptive H2 subheading. Use H3 for sub-sections. One core idea per section with supporting evidence, examples, or data.
4. **Conclusion** (75–100 words) — summarize key takeaways, reinforce the main message, end with a call to action.
5. **Meta description** — ≤160 characters, includes primary keyword, compels the click.

## Writing practices

- Write at an 8th-grade reading level for broad audiences; adjust up for technical audiences.
- Short paragraphs (2–4 sentences).
- Subheadings every 200–300 words.
- Bullet points and numbered lists to break up text.
- At least one data point, example, or quote per section.
- Active voice.
- Front-load key information in each section.

## When drafting

- Pair with `cta-patterns.md` for the conclusion CTA.
