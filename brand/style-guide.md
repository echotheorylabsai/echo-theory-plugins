# Brand Style Guide

Grammar, formatting, punctuation, and terminology rules. Read by `draft-content` (to generate compliant copy) and `brand-review` (to flag deviations).

Defaults below reflect common choices. Override any row to match this brand's preferences. When a row is left as the listed default, skills should apply that default.

---

## Grammar and Mechanics

| Rule | Default choice | Example |
|---|---|---|
| Oxford comma | **Yes** | "fast, reliable, and secure" |
| Headings case | **Sentence case** | "How to get started" |
| Contractions | **Use** | "we're" over "we are" |
| Em dash spacing | **No spaces** | "this—and more" |
| Numbers in prose | **Spell out 1–9, numerals 10+** | "five features", "10 features" |
| Percent | **%** | "50%" |
| Date format | **Month DD, YYYY** | "January 15, 2025" |
| Time format | **12-hour** | "3:00 PM" |
| Lists of fragments | **No terminal periods** | "Set up your account" |
| Lists of full sentences | **Terminal periods** | "Set up your account." |

## Formatting Conventions

- **Heading hierarchy**: one H1 per page, H2 for major sections, H3 for sub-sections. Do not skip levels.
- **Bold** for emphasis on key phrases. **Italic** for titles of works or technical terms on first use.
- **Link text** is always descriptive (never "click here" or "read more").
- **Image alt text** is required on every image.
- **Code formatting** — use backticks for inline code, fenced blocks for multi-line.
- **Callout boxes** — reserved for warnings, tips, or distinct asides; do not use for ordinary emphasis.

## Punctuation and Emphasis

- **Exclamation marks** — limited use. Never more than one consecutive.
- **Ellipses** — avoid in professional writing.
- **ALL CAPS** — avoid. Use bold for emphasis.
- **Emoji** — minimal in professional channels (blog, email, landing pages); context-appropriate in social.

## Preferred Terms (Universal)

| Use this | Not this | Notes |
|---|---|---|
| sign up (verb) | signup (verb) | "signup" is the noun form |
| log in (verb) | login (verb) | "login" is the noun/adjective form |
| set up (verb) | setup (verb) | "setup" is the noun/adjective form |
| email | e-mail | No hyphen |
| website | web site | One word |
| data is (singular) | data are | Unless the publication requires plural |

Brand-specific terminology (product names, category language) lives in `voice.md` under "Brand-Specific Terminology".

## Inclusive Language

- Use gender-neutral language; use "they/them" for unknown individuals.
- Avoid ableist language (e.g., "crazy", "blind spot", "lame", "insane").
- Use person-first language where appropriate.
- Avoid culturally specific idioms that may not translate across regions.
- Prefer "straightforward" or "simple" over "easy" (what is easy varies by person).

## Acronyms

- Spell out on first use in a document, with the acronym in parentheses.
- Subsequent uses may use the acronym alone.
- Re-spell out on first use in a new document even if used in prior documents.
